# Caso guiado: primera hora de respuesta

Aplicación didáctica estática para practicar el registro inicial y las decisiones de respuesta ante un incidente ficticio en una cooperativa.

## Contenido

- Escenario detallado con hechos confirmados, reportes y alegaciones pendientes de verificar.
- Diagrama del flujo y cronología interactiva de la primera hora.
- Seis campos guiados para construir el registro inicial del incidente.
- Retroalimentación sobre decisiones, borrador editable y exportación a `.txt`.
- Diseño adaptable a móvil y escritorio, sin dependencias ni servidor.

## Abrir localmente

Abre `index.html` en un navegador. El ejercicio no envía ni almacena respuestas en un servidor; el registro se construye en el navegador.

## Publicar en GitHub Pages

Consulta `PUBLICAR_GITHUB_MAC.md`. Para GitHub Pages, publica el contenido de esta carpeta desde la rama `main` y la raíz (`/`).

## Uso didáctico

“Cooperativa Sierra Azul” y los hechos son ficticios. Las alegaciones sobre acceso o exfiltración no se presentan como hechos comprobados. La actividad no reemplaza el procedimiento ni las decisiones autorizadas por la organización.

Referencia metodológica: [NIST SP 800-61 Rev. 3](https://doi.org/10.6028/NIST.SP.800-61r3), *Incident Response Recommendations and Considerations for Cybersecurity Risk Management: A CSF 2.0 Community Profile*.
